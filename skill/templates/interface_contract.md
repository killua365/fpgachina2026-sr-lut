# 接口合同模板

填写后用于提示词、黄金参考、驱动和测试。适用于图像与非图像批次流；填写内容必须来自算法和实际 IP 文档。

| 项目 | 填写内容 |
|---|---|
| 算法与版本 | 算法、参考实现、代码版本 |
| 平台 | 板卡/器件、PYNQ、Python、NumPy、Vivado |
| 输入 | shape、dtype、字节序、通道/采样排列、每批字节数 |
| 输出 | shape、dtype、字节序、定点缩放、舍入/饱和规则、每批字节数 |
| 数值要求 | 整数精确；浮点 atol/rtol 的依据 |
| 流接口 | AXIS宽度、TKEEP、TLAST、背压、批次是否可重叠 |
| DMA | simple模式、双向、长度位宽、对齐、DRE、内存端口 |
| 控制 | IP全名、寄存器偏移/读写属性、start/done/idle/error语义、复位方式 |
| 生命周期 | 唯一控制线程、缓存同步、缓冲区所有者、超时停止判据 |
| 时钟与资源 | 实际目标频率、时序报告、资源预算 |
| 性能 | 起止事件、计时器、窗口、去重身份、预热规则 |
| 异常 | 错误长度、超时、缺失帧、IP错误、恢复后的复测 |

失败边界：合同未定义的寄存器、时钟、地址、缓存模式不得由模型或脚本猜测。
