# PYNQ 踩坑清单

每项用于“观察—定位—修正—复核”，不是无条件修复命令。历史来源见 [证据索引](../evidence/source_index.json)；本轮回归见 [qualification](../evidence/qualification.json)。未查明根因的 UART/DP/偶发重启不写成已确认的软硬件根因。

## T1 缓存一致性

- **适用/外部场景：** PS 写入、PL 读取或反向输出的视觉、音频、ADC 批处理。
- **触发/现象：** 更换缓冲区策略后旧数据、间歇错误，重复批次结果不变。
- **来源：** 原项目区分默认同步与经过专项验证的 ACP 路径；不能只根据“Zynq”或 `cacheable` 属性推断一致性。
- **排查：** 记录分配类型、物理地址、内存端口与同步调用；用不同常量连续输入，比较完整输出。
- **处理：** 输入提交前 `sync_to_device`，输出读取前 `sync_from_device`；CPU 清过输出缓冲区后也先同步，避免脏行覆盖设备写入。
- **已验证效果：** 本轮 mock 分离 CPU/设备存储；两个算法通过。去掉同步会使设备侧输入或CPU侧输出陈旧，相关逻辑由生命周期回归覆盖。
- **边界：** 模拟测试不证明新板缓存硬件路径；ACP/HP/HPC 及 PYNQ 版本需实板确认。

## T2 DMA 等不到完成

- **适用/外部场景：** AXI Stream 图像处理、FFT、有限批次信号处理。
- **触发/现象：** `wait()` 一直等待、输出截断、TLAST 提前或丢失。
- **来源：** 原驱动显式管理输入输出字数、超时和错误状态。
- **排查：** 先核对字节数与dtype、DMA长度限制、TLAST/TKEEP、接收是否先准备，再读取DMASR错误位；区分 idle 与 halted。
- **处理：** 用带截止时间的状态轮询；输出实际字节数须等于契约；停止确认失败不能释放缓冲区。
- **已验证效果：** 本轮模拟 stalled DMA 触发超时；fake MMIO 检出 early TLAST 和 DMA error。
- **边界：** 不能通过无限加长超时修复协议错误；故障总线的单次寄存器读取本身可能不返回。

## T3 超时后过早释放或覆盖缓冲区

- **适用/外部场景：** DMA 数据采集、异步推理、双缓冲图像处理。
- **触发/现象：** 异常退出时内存损坏、下次运行随机错误、冻结结果随实时帧变化。
- **来源：** 原 engine 在确认 DMA Halted/复位完成之前不释放；帧显示另有缓冲区所有权管理。
- **排查：** 分开记录 CPU、DMA 和显示设备的占用，检查超时分支和每个引用的生命周期。
- **处理：** 未确认停止时 quarantine 并保留强引用；不得继续复用。需要独立保存的结果复制成快照。
- **已验证效果：** 本轮停止失败时无 free 事件；后续 run 被拒绝，确认停止后可释放；连续两批不改变第一批返回副本。
- **边界：** 只停止 AXI DMA 不代表其他显示消费者停止；终止 Python 进程也不能代替硬件停止确认。

## T4 Overlay 切换后旧句柄访问

- **适用/外部场景：** 多算子切换、可重配置教学实验、视觉/音频模式切换。
- **触发/现象：** 重载后GPIO/寄存器访问异常、后台线程仍使用旧 IP 对象。
- **来源：** 原项目 Engine 生命周期要求停止 producer，重新载入期间无后台 GPIO 访问。
- **排查：** 找出采集、计算、显示、按钮轮询所有者，核对是否有跨代次的句柄和结果。
- **处理：** 停采集/提交→停止并确认DMA→处理消费者持有的缓冲区→加载→重建IP/缓冲区→恢复采集。
- **已验证效果：** 原项目已有切换/恢复记录；新模板要求单会话独占且显式下载，未新增多Overlay实板验收。
- **边界：** 部分重配置、并发共享属于额外设计，不适用直接重载模板。

## T5 像素格式、步长与 NumPy 版本

- **适用/外部场景：** 图像、音频交错通道、FPGA输出数据打包。
- **触发/现象：** 色偏、X字节污染、ROI切片转换异常；主机通过而ARM失败。
- **来源：** r11 的 ARM NumPy 1.21 非连续 dtype view 失败，改成保留原行步长的逐行解释后通过；本轮 NumPy 2.x `device` 属性冲突也有实际失败记录。
- **排查：** 打印dtype、shape、strides、C连续性、字节顺序和库版本；查看完整字节而不是屏幕观感。
- **处理：** 明确打包合同，必要时受控复制；保留行步长；辅助属性避免占用库已有名称。
- **已验证效果：** 历史 ARM 28 项通过（5项修正后复测）；本轮非连续输入、类型错误、整数差值溢出测试通过。
- **边界：** x86测试无法替代ARM性能与原生代码检查；不要给所有数组强制 reinterpret 成uint32。

## T6 渲染导致 FPS 和鼠标一起变慢

- **适用/外部场景：** PYNQ实时监控、图像仪器、波形与状态显示。
- **触发/现象：** 增加覆盖层后鼠标卡顿，同时处理/显示帧率下降。
- **来源：** r11确认ARM逐通道NumPy背景填充阻塞绘制与鼠标轮询。
- **排查：** 测量事件轮询间隔、背景填充、缩放、合成与DMA/PL耗时；检查新增全帧写入和复制。
- **处理：** 对已确认RGBX布局使用整字填充、缓存静态文字，只更新变化区域；保持完整输出字节一致。
- **已验证效果：** 历史记录 baseline 12.0794 fps、修复短测22.6143 fps，用户确认手感恢复；不是同长度持续对照实验。
- **边界：** 该数值不代表新模板性能；对其他格式、对齐和平台必须先验证字节正确再测性能。

## T7 将刷新率当作算法吞吐

- **适用/外部场景：** 视频输出、实时推理、采样仪器。
- **触发/现象：** 60 Hz显示器显示重复帧，却报告算法60fps；只记录提交而不确认完成。
- **来源：** 本队用 Nexys 完整新扫描事件核验，两段300秒结果区别于采集和提交率。
- **排查：** 明确计时点、帧/批次身份、代次、固定窗口及日志是否完整。
- **处理：** 同一个时钟域内按成功完成的新身份计数；换模式/重启分开统计；重复重绘不计。
- **已验证效果：** 历史 r5全屏21.7567、分屏22.4233fps；本轮合成事件测试检出重复计数并排除其他阶段/代次。
- **边界：** 上游日志丢失时只能标记不完整；不能把模拟事件率或短窗口当持续性能结论。

## T8 过期任务与快照所有权

- **适用/外部场景：** 工业视觉冻结分析、推理结果异步展示、ROI后台评分。
- **触发/现象：** 切图后旧分数回填、冻结画面变化、输入与处理结果来自不同帧。
- **来源：** 项目冻结/保存与图片后台评分需绑定帧身份、图片、倍率及ROI。
- **排查：** 检查每个结果的generation/token及引用是否指向循环缓冲区。
- **处理：** 过期结果丢弃，输入/输出同代次提交；冻结和保存使用独立副本。
- **已验证效果：** 原项目用户已确认冻结交互；本轮session返回独立副本，连续运行回归证明旧输出不被覆盖。
- **边界：** 本包未复制整个GUI或后台评分线程；需要使用者给异步任务增加自己的代次检查。

## T9 环境、路径与文件身份

- **适用/外部场景：** 多电脑Vivado构建、实验室交接、板端包升级。
- **触发/现象：** 路径编码失败、相同文件名却版本不一致、依赖版本差异。
- **来源：** 本项目历史重建采用英文工作目录并校验源文件；BIT/HWH、载荷和证据分别记录哈希。
- **排查：** 核对工具版本、实际解析路径、BIT/HWH同次构建身份和原始时序报告。
- **处理：** 新工程文件名遵循赛事英文规范；脚本用相对配置与显式解释器；交付附SHA-256和原始报告。
- **已验证效果：** 本轮目录独立运行和完整清单检查；原Vivado报告可离线重读。
- **边界：** 哈希一致不证明源文件正确，也不证明外部许可证/驱动/系统镜像已齐全。
