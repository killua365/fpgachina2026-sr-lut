# 赛题要求逐条对照

依据用户提供的《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA 赛道选题指南—AMD》，自主选题赛道 3.3。原文印刷页 19—22，对应 PDF 第 22—25 页。

| 条款/要求 | 本包对应交付 | 核验方式与限制 |
|---|---|---|
| 3.3.5.2：置于 skill/，含 README.md | 根目录 README 和四类入口 | 独立 ZIP 保留 `skill/` 根目录 |
| 适用范围、使用方法、失效条件 | Skill README、专题指南、migration.md、故障卡 | 每项明确软硬件边界与执行步骤 |
| 任一种或多种形式 | 四套提示词、案例模板、校验脚本、踩坑清单 | 本次四类均提供，不把“四类全做”误写成赛事强制要求 |
| 陌生队伍能否直接用于自己的题目 | 无 SR-LUT 导入的核心模板、独立例子及相对路径配置 | 临时独立目录复跑；更换硬件仍需新的 BIT/HWH |
| 已验证效果 | evidence 中本轮回归、两外部场景、项目报告解析与历史实测来源 | 每份记录说明是否访问硬件、版本及验证阶段 |
| 失败或观察的来源 | derivation、collaboration_record、source_index、结构化故障卡 | 新包真实失败与修复记录保留；历史复盘不冒充逐字聊天 |
| 3.3.2：通用 PYNQ，说明题目外场景 | PYNQ Overlay/allocate/DMA 模板及 migration 场景表 | 已脱离 SR 算法；未声称第二板实测 |
| 3.3.5.3：提炼过程、验证方法与边界 | evidence/derivation.md | 可作为主设计报告 Skill 章节的依据 |
| 3.3.3.1/3.3.5.3：模型协作记录 | 本包任务范围的真实用户要求节选、模型执行决策、测试失败与修正 | 不等于完整项目历次模型对话档案；主报告如需完整档案应另行整理 |
| 3.3.5.4：英文目录/文件名 | 本包新增文件英文命名，保留条款明确指定的 README.md | 不宣称已对整个主项目历史中文文件完成改名 |
| 3.3.3.3：强烈要求开源，推荐 MIT/Apache-2.0 | provenance.md 保留来源和授权边界 | 本次未公开发布或替团队确定整个项目的许可证 |

技能包及大模型协作共同属于评分项；通用 PYNQ Skill 另有加分，指南未给出该加分的具体数值。完成材料不代表已经获得赛事认证或加分。
