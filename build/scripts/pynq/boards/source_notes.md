# PYNQ-Z2 Board Definition

The unmodified TUL PYNQ-Z2 board, pin map, preset and image were copied from
the existing `pynq-z2_board_files-main` download in the workspace.
The XML declares vendor `tul.com.tw`, board `pynq-z2`, revision `1.0`, and
part `xc7z020clg400-1`. The upstream board URL is http://www.tul.com.tw.

`board_repository.tcl` registers this directory for project builds. No copy
into the Vivado installation or global user Tcl startup file is required.
